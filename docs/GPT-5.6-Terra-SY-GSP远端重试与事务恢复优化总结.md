# GPT-5.6-Terra：SY-GSP 远端重试与事务恢复优化总结

## 本轮修改

- 远端引用错误携带实际远端 HEAD，便于区分重复失败；
- 相同远端失败指纹连续出现时停止无意义重试，避免重复提交；
- 不再把连续引用确认失败直接断言为存在其它设备写入；
- 冲突决策增加 Map/对象兼容与无效决策校验；
- 目录精确忽略规则与远端文件过滤保持一致；
- 远端分支本身 404 与 commit/tree 404 分开处理；
- 工作区时间兼容秒、毫秒和 ISO 格式；
- 诊断增加本地和远端阶段日志；
- 构建产物同步更新。
