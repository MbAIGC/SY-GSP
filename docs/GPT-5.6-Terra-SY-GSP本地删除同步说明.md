# SY-GSP 本地删除同步说明

## 自动同步行为

在正常自动同步中，本地删除的文件不会立即被远端版本重新下载。只有满足以下条件时，才会生成远端删除提交：

- 已存在已确认的同步 BASE；
- 远端文件仍与 BASE 一致，没有被远端单独修改；
- 本地目录扫描完整；
- 本地清单记录过该文件，能够证明它曾属于同步范围。

满足条件后，日志会记录「远端删除已提交」，并在同步成功后移除对应清单记录。

## 保护行为

以下情况会跳过远端删除并保留远端文件：

- 本地目录枚举异常；
- 本地清单缺失；
- 当前路径不属于同步范围；
- 远端文件在 BASE 之后发生过修改。

日志会记录「远端删除已跳过」及路径，避免把安全拦截误认为同步成功删除。

## 同步重建

历史状态异常或首次同步不适合自动判断时，可使用菜单中的「同步重建」。它会先对比本地和远端，再由用户明确选择一端作为基准。
