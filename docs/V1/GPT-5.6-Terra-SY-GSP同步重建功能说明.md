# SY-GSP 同步重建功能说明

## 功能

菜单新增「同步重建」。它会先只读检查当前同步范围的本地文件与远端文件，再由用户选择一端作为唯一基准。

## 校验内容

- 本地文件数量与远端文件数量；
- 仅本地、仅远端、内容不同、内容相同的文件；
- 当前 BASE；
- 本地清单残留；
- 未处理冲突残留；
- 本地目录枚举是否完整；
- 远端分支、提交和文件树是否完整可读。

## 执行

选择「以远端为准」会执行远端镜像本地；选择「以本地为准」会执行本地镜像远端。方向选择后会弹出二次确认窗口，显示方向、待删除文件数量和路径摘要；只有点击「确认重建」才会执行批量覆盖或删除。

同步重建会暂停自动同步；校验失败不执行清理，镜像执行仍复用现有 CAS、删除保护、本地并发检查、manifest 和 BASE 规则。以本地为准完成远端写入后，会重新读取 GitHub 文件树并校验远端路径集合是否与本地一致；仍有残留路径时直接报告失败，不报告重建成功。

## 限制

执行期间如果本地仍在持续创建或修改文件，现有并发保护会暂停操作。当前功能已接入现有强制方向同步链路，真实思源和 GitHub 环境仍需实际验证。
