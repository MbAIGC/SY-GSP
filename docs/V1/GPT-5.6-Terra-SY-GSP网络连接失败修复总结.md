# GPT-5.6-Terra：SY-GSP 网络连接失败修复总结

## 问题定位

最新版本为远端 HEAD 读取增加了 `Cache-Control` 和 `Pragma` 请求头。虽然目的是避免读取缓存，但这些自定义请求头可能触发浏览器跨域预检；预检失败会被 HTTP 客户端统一显示为“网络连接失败”。

## 修复

移除新增的自定义缓存请求头，改用远端 HEAD 请求的时间戳查询参数避免缓存：

```text
_sgsp_ts=当前时间
```

这样仍能降低读取旧引用的概率，同时不改变请求方法和请求头，不额外触发 CORS 预检。

## 验证

```text
npm test: 148/148 通过
npm run build: 成功
npm run smoke: 12/12 通过
```

真实 GitHub/思源环境是否存在代理缓存，仍需重新加载插件后观察运行日志确认。
